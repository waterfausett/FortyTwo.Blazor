# ML Hints in Practice Matches Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A player in a practice match (mode `bots`) can tap **Hint** on their turn and see what the ML bot would bid, name as trump or play, with a short why.

**Architecture:**
- **Bot package:** the bot gets an `explain` method that shares the bot's own decision code. A hint can therefore never disagree with what a bot in that seat would do.
- **Worker:** `MatchDO.hint` runs it behind `GET /api/matches/:id/games/current/hint`. A cold isolate answers `warming` while the model loads one piece per call.
- **Client:** `@fortytwo/client` retries every 400 ms and turns a hint into display text. The web and mobile apps add a Hint button, a hint card, and a mark on the suggested bid, trump or domino.

**Tech Stack:**
- TypeScript npm workspaces (`apps/*`, `packages/*`), Hono on Cloudflare Workers with Durable Objects;
- tests: vitest (packages, web, worker via `@cloudflare/vitest-plugin`) and jest + `@testing-library/react-native` (mobile);
- UI: React (web, Vite) and React Native (Expo).

**Spec:** `docs/superpowers/specs/2026-10-17-ml-hints-design.md`

## Global Constraints

- Hints only in matches whose `matchMode(match) === 'bots'` with default house rules. Every other mode is refused (400).
- Retry delay **400 ms**. Give up after **10 s** of `warming`.
- A domino is rated `best` at gap 0, `close` when the gap is under **0.1** marks, and `weaker` otherwise.
- The bid card shows at most **3** option rows, and so does the trump card.
- A hint is computed only from the caller's own hand and public play. It never saves, broadcasts, or acts for the player.
- `BOTS_ENABLED=false` turns hints off, along with bots.

```ts
// A hint (GET /api/matches/:id/games/current/hint, practice matches only): what the ML bot would
// do in the caller's seat, and the numbers behind it (@fortytwo/bot's explain.ts). Bids and suits
// are the rules engine's enum values; a domino is the rules' { id, top, bottom }.
export interface HintDomino {
  id: string;
  top: number;
  bottom: number;
}

// A bid and the trump the bot would play it in, with its chance of making it. Pass, Plunge (whose
// trump the partner names) and a forced bid with no option have no trump; Pass and that forced bid
// have no P(make) either.
export interface BidSuggestion {
  bid: number;
  trump: number | null;
  pMake: number | null;
}

export interface TrumpSuggestion {
  trump: number;
  pMake: number | null;
}

// One legal domino: the team's expected marks for the hand if it's played, how far that is below
// the best, and the rating shown for it.
export interface PlayRating {
  domino: HintDomino;
  marks: number;
  gap: number;
  rating: 'best' | 'close' | 'weaker';
}

export type Hint =
  | { kind: 'bid'; suggestion: BidSuggestion; options: BidSuggestion[] }
  | { kind: 'trump'; suggestion: TrumpSuggestion; options: TrumpSuggestion[] }
  | { kind: 'play'; dominoes: PlayRating[] };

// 'warming': the model is still loading in this isolate (one piece per call) - ask again shortly.
// 'unavailable': the model couldn't be loaded; hints are off until it can.
export type HintResponse = { status: 'warming' } | { status: 'unavailable' } | { status: 'ready'; hint: Hint };
```

```ts
// The bot's three decisions with the numbers behind them, shared by the bot (bot.ts), which acts
// on the decision alone, and by hints (explain.ts), which show the numbers too - so a hint can
// never disagree with what a bot in that seat would do.
import {
  Bid, Suit, availableBids, availableTrumps, gameWinningTeam, type Domino, type Game, type MatchState,
} from '@fortytwo/rules';
import { bidTable, chooseBid, optionsFromTable, type BidDecision, type Option } from './bidding';
import { toIndex } from './dominoes';
import { OBS_DIM, encodeCandidates } from './encode';
import { scoreCandidates } from './mlp';
import { buildView, seatOf } from './view';
import { legalPlays } from './legal';
import type { BotWeights } from './weights';

export interface Decider {
  // choose_bid's decision, the options it chose from, and the legal bids.
  bid(match: MatchState, playerId: string): { decision: BidDecision; options: Option[]; legal: Bid[] };
  // Every legal trump the bot would consider, best first; the first is the one it names. A tie
  // keeps option order, so the first is the same first maximum the bot always picked.
  trumps(match: MatchState, playerId: string): { trump: Suit; pMake: number | null }[];
  // Every legal domino in hand order, with its Q-value: expected hand marks for the player's team.
  // Null throughout when there's no inference to run (one legal domino, or the hand is decided).
  plays(match: MatchState, playerId: string): { domino: Domino; q: number | null }[];
}

const handOf = (game: Game, playerId: string) => game.hands.find((h) => h.playerId === playerId)!.dominoes;

// Highest pMake first. Array.prototype.sort is stable, so equal ones keep their order.
function bestFirst<T extends { pMake: number }>(items: T[]): T[] {
  return [...items].sort((a, b) => b.pMake - a.pMake);
}

export function createDecider(w: BotWeights): Decider {
  const cfg = { makeThreshold: w.manifest.makeThreshold, overbidPartnerThreshold: w.manifest.overbidPartnerThreshold };
  const table = (game: Game, playerId: string) => bidTable(w, handOf(game, playerId).map(toIndex));

  return {
    bid(match, playerId) {
      const game = match.currentGame;
      const seat = seatOf(match, playerId);
      const legal = availableBids(game, playerId);
      const ctx = {
        legal,
        partnerHolds: game.biddingPlayerId !== null && seatOf(match, game.biddingPlayerId) === (seat + 2) % 4,
        lastToBid: game.hands.every((h) => h.playerId === playerId || h.bid !== null),
      };
      const options = optionsFromTable(table(game, playerId), legal);
      return { decision: chooseBid(options, ctx, cfg), options, legal };
    },

    trumps(match, playerId) {
      const game = match.currentGame;
      const legal = availableTrumps(game);
      const t = table(game, playerId);
      if (game.bid === Bid.Plunge && game.biddingPlayerId !== playerId) {
        return bestFirst(legal.map((s) => ({ trump: s, pMake: t.high[s === Suit.None ? 7 : s] })));
      }
      const atBid = optionsFromTable(t, [game.bid!]).filter((o) => legal.includes(o.trump as Suit));
      return atBid.length
        ? bestFirst(atBid.map((o) => ({ trump: o.trump as Suit, pMake: o.pMake })))
        : [{ trump: legal[0], pMake: null }];
    },

    plays(match, playerId) {
      const game = match.currentGame;
      const legal = legalPlays(game, playerId);
      if (legal.length === 1 || gameWinningTeam(game) !== null) return legal.map((domino) => ({ domino, q: null }));
      const rows = encodeCandidates(buildView(match, playerId), legal.map(toIndex));
      const q = scoreCandidates(w.play, OBS_DIM, rows);
      return legal.map((domino, i) => ({ domino, q: q[i] }));
    },
  };
}
```

```ts
// Follow suit: holding the led suit, you must play it (validation.assertValidDomino).
import { isOfSuit, type Domino, type Game } from '@fortytwo/rules';

export function legalPlays(game: Game, playerId: string): Domino[] {
  const hand = game.hands.find((h) => h.playerId === playerId)!.dominoes;
  const suit = game.currentTrick.suit;
  if (suit === null) return hand;
  const following = hand.filter((d) => isOfSuit(d, suit, game.trump));
  return following.length ? following : hand;
}
```

```ts
// A hint: what the bot would do in a player's seat, and the numbers behind it, for a human in a
// practice match (#76). Built on the bot's own decisions (decisions.ts), so the suggestion is
// always exactly the bot's move. Everything comes from the asker's own hand and the public play -
// buildView and bidTable read nothing else (test/explain.test.ts proves it).
import type { BidSuggestion, Hint, PlayRating } from '@fortytwo/api-types';
import { Bid, ValidationError, gameWinningTeam, type MatchState } from '@fortytwo/rules';
import type { Option } from './bidding';
import type { Decider } from './decisions';

// Below this many expected marks short of the best, a domino is "close" rather than "weaker".
export const CLOSE_GAP = 0.1;
// Rows a bid or trump hint lists.
const ROWS = 3;

// A hint is for the asker's own turn to bid, name trump or play, while the hand is still open.
export function assertCanHint(match: MatchState, playerId: string): void {
  const game = match.currentGame;
  if (game.currentPlayerId !== playerId) throw new ValidationError('Not your turn', 'Hints are for your own turn.');
  if (gameWinningTeam(game) !== null) throw new ValidationError('Hand decided', 'This hand is already decided.');
}

export function explainWith(d: Decider, match: MatchState, playerId: string): Hint {
  assertCanHint(match, playerId);
  const game = match.currentGame;
  if (game.hands.some((h) => h.bid === null)) return bidHint(d, match, playerId);
  if (game.trump === null) {
    const ranked = d.trumps(match, playerId);
    return { kind: 'trump', suggestion: ranked[0], options: ranked.slice(0, ROWS) };
  }
  return playHint(d, match, playerId);
}

// The partner names a Plunge's trump, so the bid has none of its own.
function suggestion(o: { bid: number; trump: number | null; pMake: number | null }): BidSuggestion {
  return { bid: o.bid, trump: o.bid === Bid.Plunge ? null : o.trump, pMake: o.pMake };
}

// The suggested bid between its neighbours (or the lowest bids, when the bot would pass), each in
// the trump that makes it likeliest - the same best-per-bid choose_bid weighs.
function bidHint(d: Decider, match: MatchState, playerId: string): Hint {
  const { decision, options, legal } = d.bid(match, playerId);
  const best = new Map<number, Option>();
  for (const o of options) {
    const cur = best.get(o.bid);
    if (cur === undefined || o.pMake > cur.pMake) best.set(o.bid, o);
  }
  const rows = legal
    .filter((b) => b !== Bid.Pass)
    .sort((a, b) => a - b)
    .map((b) => (best.has(b) ? suggestion(best.get(b)!) : { bid: b, trump: null, pMake: null }));
  const at = rows.findIndex((r) => r.bid === decision.bid);
  const start = at < 0 ? 0 : Math.max(0, Math.min(at - 1, rows.length - ROWS));
  return { kind: 'bid', suggestion: suggestion(decision), options: rows.slice(start, start + ROWS) };
}

function playHint(d: Decider, match: MatchState, playerId: string): Hint {
  const plays = d.plays(match, playerId);
  if (plays.some((p) => p.q === null)) {
    return { kind: 'play', dominoes: plays.map((p) => ({ domino: p.domino, marks: 0, gap: 0, rating: 'best' })) };
  }
  const top = Math.max(...plays.map((p) => p.q!));
  const rated = plays.map((p): PlayRating => {
    const gap = top - p.q!;
    return { domino: p.domino, marks: p.q!, gap, rating: gap === 0 ? 'best' : gap < CLOSE_GAP ? 'close' : 'weaker' };
  });
  // Stable, so tied dominoes keep hand order and the first is the one the bot would play.
  return { kind: 'play', dominoes: rated.sort((a, b) => a.gap - b.gap) };
}
```

```ts
// rules the model learned, while bots are on, on their own turn of an open hand. Hints stay out of

export function assertHintable(match: MatchState, playerId: string, enabled: boolean): void {
```

```ts
// Hints in a practice match (#76), the parts both apps share: when the Hint button shows, asking
// the Worker until its model has warmed up, and the words a hint is shown in.
import {
  Bid, bidToPrettyString, isLow, lowDoublesToPrettyString, matchMode, suitToPrettyString, type MatchState, type Suit,
} from '@fortytwo/rules';
import type { BidSuggestion, Hint, HintDomino, HintResponse } from '@fortytwo/api-types';
import { ApiError } from './api';
import { describeMatch } from './matchView';

// A cold Worker loads its model one piece per call (about 7 calls); spaced this far apart.
export const HINT_RETRY_MS = 400;
export const HINT_GIVE_UP_MS = 10_000;
export const HINT_UNAVAILABLE = "Hints aren't available right now.";

const aborted = () => Object.assign(new Error('Hint request aborted'), { name: 'AbortError' });
export const isAbort = (error: unknown): boolean => error instanceof Error && error.name === 'AbortError';

// Asks for a hint until the Worker stops answering 'warming'. Rejects with HINT_UNAVAILABLE when
// the model is unavailable or still warming after HINT_GIVE_UP_MS, with the Worker's own error for
// a refusal, and with an AbortError once `signal` aborts (callers drop that one silently).
export async function fetchHint(getHint: () => Promise<HintResponse>, signal?: AbortSignal): Promise<Hint> {
  const started = Date.now();
  for (;;) {
    if (signal?.aborted) throw aborted();
    const res = await getHint();
    if (signal?.aborted) throw aborted();
    if (res.status === 'ready') return res.hint;
    if (res.status === 'unavailable' || Date.now() - started >= HINT_GIVE_UP_MS) throw new Error(HINT_UNAVAILABLE);
    await new Promise<void>((resolve, reject) => {
      const timer = setTimeout(resolve, HINT_RETRY_MS);
      signal?.addEventListener('abort', () => {
        clearTimeout(timer);
        reject(aborted());
      }, { once: true });
    });
  }
}

// The Hint button shows in a practice match with bots on, on my turn to bid, name trump or play,
// while the hand is still open (the Worker's hints.ts makes the final call).
export function canAskForHint(match: MatchState | null, myPlayerId: string | undefined, botsEnabled: boolean): boolean {
  if (!match || !myPlayerId || !botsEnabled || matchMode(match) !== 'bots') return false;
  if (!match.players.some((p) => p.playerId === myPlayerId)) return false;
  const view = describeMatch(match, myPlayerId);
  return !view.isHandOver && (view.canBid || view.canSelectTrump || view.isMyTurnToPlay);
}

// Names the decision a hint was asked for: any change to the match is a new one, so a hint never
// outlives the turn it was for.
export function hintTurnKey(match: MatchState): string {
  return `${match.currentGame.id}:${match.currentGame.currentPlayerId}:${match.updatedOn}`;
}

export function hintErrorMessage(error: unknown): string {
  if (error instanceof ApiError) return error.detail ?? error.title;
  return error instanceof Error ? error.message : HINT_UNAVAILABLE;
}

const percent = (p: number | null) => (p === null ? '' : `${Math.round(p * 100)}%`);
const marks = (gap: number) => `−${gap.toFixed(2)} marks`;

function trumpLabel(trump: number): string {
  return isLow(trump as Suit) ? `Low (doubles ${lowDoublesToPrettyString(trump as Suit).toLowerCase()})` : suitToPrettyString(trump as Suit);
}

function bidLabel(s: BidSuggestion): string {
  const bid = bidToPrettyString(s.bid as Bid);
  return s.trump === null ? bid : `${bid} · ${trumpLabel(s.trump)}`;
}

// High end first, as a domino is usually read: 6-4.
const dominoLabel = (d: HintDomino) => `${Math.max(d.top, d.bottom)}-${Math.min(d.top, d.bottom)}`;

export function hintHeadline(hint: Hint): string {
  switch (hint.kind) {
    case 'bid': {
      const s = hint.suggestion;
      if (s.bid === Bid.Pass) return 'Pass';
      return s.pMake === null ? `Bid ${bidLabel(s)}` : `Bid ${bidLabel(s)}, ${percent(s.pMake)} to make`;
    }
    case 'trump': {
      const s = hint.suggestion;
      return s.pMake === null ? trumpLabel(s.trump) : `${trumpLabel(s.trump)}, ${percent(s.pMake)} to make`;
    }
    case 'play':
      return `Play ${dominoLabel(hint.dominoes[0].domino)}`;
  }
}

export interface HintRow {
  key: string;
  label: string;
  detail: string;
  suggested: boolean;
}

export function hintRows(hint: Hint): HintRow[] {
  switch (hint.kind) {
    case 'bid':
      return hint.options.map((o) => ({
        key: String(o.bid), label: bidLabel(o), detail: percent(o.pMake), suggested: o.bid === hint.suggestion.bid,
      }));
    case 'trump':
      return hint.options.map((o, i) => ({
        key: String(o.trump), label: trumpLabel(o.trump), detail: percent(o.pMake), suggested: i === 0,
      }));
    case 'play':
      return hint.dominoes.map((r) => ({
        key: r.domino.id,
        label: dominoLabel(r.domino),
        detail: r.rating === 'best' ? 'best' : `${r.rating} (${marks(r.gap)})`,
        suggested: r.rating === 'best',
      }));
  }
}

export const suggestedBid = (hint: Hint | null): number | null => (hint?.kind === 'bid' ? hint.suggestion.bid : null);
export const suggestedTrump = (hint: Hint | null): number | null => (hint?.kind === 'trump' ? hint.suggestion.trump : null);
export const suggestedDominoIds = (hint: Hint | null): string[] =>
  hint?.kind === 'play' ? hint.dominoes.filter((r) => r.rating === 'best').map((r) => r.domino.id) : [];
```

```ts
// The Hint button's state for this turn (practice matches only, #76): nothing is asked until the
// player presses it, an answer is kept for the rest of the turn, and a new turn - or an answer
// arriving after the turn has moved on - leaves nothing behind. The asking and the words live in
// @fortytwo/client's hints.ts.
import { useCallback, useEffect, useRef, useState } from 'react';
import type { MatchState } from '@fortytwo/rules';
import type { Hint, HintResponse } from '@fortytwo/api-types';
import { canAskForHint, fetchHint, hintErrorMessage, hintTurnKey, isAbort } from '@fortytwo/client';

export type HintState =
  | { status: 'idle' }
  | { status: 'loading' }
  | { status: 'ready'; hint: Hint }
  | { status: 'error'; message: string };

export interface HintController {
  available: boolean;
  state: HintState;
  ask: () => void;
  // The hint on show, for marking the suggestion in the bid, trump and hand controls.
  hint: Hint | null;
}

const IDLE: HintState = { status: 'idle' };

// `paused`: a pre-play is queued, so the domino will play itself - no hint for this turn.
export function useHint(
  match: MatchState | null,
  myPlayerId: string | undefined,
  botsEnabled: boolean,
  getHint: () => Promise<HintResponse>,
  paused = false
): HintController {
  const available = !paused && canAskForHint(match, myPlayerId, botsEnabled);
  const key = match ? hintTurnKey(match) : null;
  const [entry, setEntry] = useState<{ key: string | null; state: HintState }>({ key: null, state: IDLE });
  const abortRef = useRef<AbortController | null>(null);
  const getHintRef = useRef(getHint);
  useEffect(() => {
    getHintRef.current = getHint;
  });

  // Leaving a turn stops whatever was still asking about it.
  useEffect(() => () => abortRef.current?.abort(), [key]);

  const current = entry.key === key ? entry.state : IDLE;
  const state = available ? current : IDLE;

  const ask = useCallback(() => {
    if (key === null || current.status === 'loading' || current.status === 'ready') return;
    abortRef.current?.abort();
    const abort = new AbortController();
    abortRef.current = abort;
    setEntry({ key, state: { status: 'loading' } });
    fetchHint(() => getHintRef.current(), abort.signal).then(
      (hint) => {
        if (!abort.signal.aborted) setEntry({ key, state: { status: 'ready', hint } });
      },
      (error: unknown) => {
        if (!abort.signal.aborted && !isAbort(error)) setEntry({ key, state: { status: 'error', message: hintErrorMessage(error) } });
      }
    );
  }, [key, current.status]);

  return { available, state, ask, hint: state.status === 'ready' ? state.hint : null };
}
```

```tsx
// The Hint button and the hint card above the hand (practice matches only). The card advises; the
// player still makes the move.
import { Pressable, StyleSheet, Text, View } from 'react-native';
import { hintHeadline, hintRows } from '@fortytwo/client';
import type { HintController } from '@/match/useHint';
import { colors, fonts } from './theme';

export function HintPanel({ hint }: { hint: HintController }) {
  if (!hint.available) return null;
  const { state } = hint;
  return (
    <View style={styles.panel} accessibilityLabel="Hint">
      {state.status === 'idle' && (
        <Pressable style={styles.button} onPress={hint.ask} accessibilityRole="button">
          <Text style={styles.buttonText}>Hint</Text>
        </Pressable>
      )}
      {state.status === 'loading' && <Text style={styles.status}>Thinking…</Text>}
      {state.status === 'error' && (
        <View style={styles.errorRow}>
          <Text style={styles.status}>{state.message}</Text>
          <Pressable style={styles.button} onPress={hint.ask} accessibilityRole="button">
            <Text style={styles.buttonText}>Try again</Text>
          </Pressable>
        </View>
      )}
      {state.status === 'ready' && (
        <View style={styles.card}>
          <Text style={styles.headline}>{hintHeadline(state.hint)}</Text>
          {hintRows(state.hint).map((row) => (
            <View
              key={row.key}
              style={[styles.row, row.suggested && styles.suggested]}
              accessible
              accessibilityLabel={`${row.label}, ${row.detail}${row.suggested ? ', suggested' : ''}`}
            >
              <Text style={styles.rowText}>{row.label}</Text>
              <Text style={styles.rowText}>{row.detail}</Text>
            </View>
          ))}
        </View>
      )}
    </View>
  );
}

const styles = StyleSheet.create({
  panel: { alignItems: 'center', marginVertical: 6 },
  button: { paddingHorizontal: 14, paddingVertical: 6, borderRadius: 8, borderWidth: 1, borderColor: colors.inkMuted },
```

```ts
    } else if (game.trump === null) {
```
